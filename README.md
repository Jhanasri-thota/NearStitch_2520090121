# NearStitch – Local Tailor Booking Website

##  Project Overview

NearStitch is a simple web application that helps users find nearby tailoring services and book stitching services easily.
The platform allows customers to search for tailors, view available services and prices, and schedule a pickup request for stitching orders.

This project was developed as part of the **Front-End Web Development (FWD)** coursework.



##  Objectives

* Provide a simple platform to discover nearby tailors
* Allow users to book stitching services online
* Demonstrate the use of core front-end web technologies
* Implement responsive and interactive UI features



##  Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and layout design
* **JavaScript** – Interactivity and dynamic behavior



##  Features

* Search for nearby tailoring shops
* Tailor profile listings with service details
* Price table for stitching services
* Pickup request booking form with address input
* Booking confirmation modal
* Dark mode toggle
* Responsive user interface



## System Architecture

The system follows a simple client-side architecture:

User Interface → Search & Booking Form → JavaScript Processing → Display Tailor Listings → Booking Confirmation
